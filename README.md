# Passion4Profession Blog

A React and Vite knowledge blog for clear technical essays, computing notes, and practical learning resources.

![Passion4Profession Blog preview](screenshot.png)

## Features

- Searchable blog archive with date-aware post navigation
- Lazy-loaded routes for technical articles
- Dark and light themes saved in local storage
- Responsive layout with mobile sidebar navigation
- Share controls, scroll-to-top control, and icon-only footer links
- Generated blog index files for maintainable content

## Tech stack

- React
- Vite
- React Router
- styled-components
- Material UI
- react-icons

## Run locally

\`\`\`bash
npm install
npm run dev
\`\`\`

Build and deploy:

\`\`\`bash
npm run build
npm run deploy
\`\`\`
